# Security Policy

RustUse accepts private reports for vulnerabilities affecting this crate and its release path.

## Supported versions

| Surface                               | Status                                            |
| ------------------------------------- | ------------------------------------------------- |
| `main`                                | Supported on a best-effort basis until superseded |
| Latest published pre-1.0 release line | Supported                                         |
| Older releases                        | Not guaranteed                                    |

## Reporting a vulnerability

Report vulnerabilities privately to ferris@rustuse.org.

- Do not open a public issue for a suspected vulnerability.
- Include reproduction steps, affected versions, and enabled features.
- Include impact details or a minimized test case when available.
